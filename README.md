# be11

Premium cricket ground booking platform.

## Architecture

This project is initialized as a clean, feature-based, monorepo project architecture.

### Directory Structure

- `frontend/` - React frontend application client.
- `backend/` - Node.js Express backend API service.
- `shared/` - Common schemas, constants, types, and utility helpers shared between frontend and backend.
- `docs/` - Architecture, API, database, setup, and deployment guides.
- `docker/` - Docker deployment setups for dev, local, and production configurations.
